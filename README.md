## Описание

Астрологическое приложение для расчёта судьбы человека по дню недели его
рождения. Пользователь вводит дату рождения (стандартный элемент ввода даты
не используется), программа проверяет корректность даты, определяет день
недели и выводит соответствующее описание судьбы. Последние введённые данные
запоминаются в главной форме и восстанавливаются при повторном вводе.
При некорректном вводе выдаётся сообщение об ошибке.

Архитектура построена по шаблону MVC с активной моделью: модель хранит данные
и выполняет вычисления, самостоятельно оповещая наблюдателей (паттерн
Observer) об изменении состояния; представление подписывается на модель;
контроллер обрабатывает действия пользователя.
